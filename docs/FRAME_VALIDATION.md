# Frame Validation

Date: 2026-06-07

`GlyphFrameValidator` is the safety gate for all Matrix output.

## Required Rules

1. Matrix size must be 13x13.
2. Accidental all-on frames are invalid.
3. Accidental all-off frames are invalid during active animations unless `allowAllOff` is explicitly set.
4. Pixels outside the circular safe area are invalid unless `allowOffMaskPixels` is explicitly set.
5. Full-matrix flashes are invalid unless intentional and debug-enabled.
6. Intensities must be normalized to the internal range 0..100.
7. Single stray pixels far away from the main shape are warnings or errors unless `particleEffect` is set.
8. Icon bounding boxes must be large enough for the icon type.
9. Icons must be centered unless marked directional.
10. Text frames must be generated by the registered `GlyphTextRenderer`.

## Production Behavior

- Normalize/sanitize when it is safe.
- Reuse the previous valid frame when a frame cannot be sanitized.
- Never replace invalid output with an all-on, full-bright, or full-matrix flash frame.

## Debug Behavior

Debug builds should log:

- Source Toy / animation id.
- Validation severity.
- Bounding box.
- Center of mass.
- Lit pixel count.
- Min/max intensity.
- Unique intensity count.
- Circular-mask violations.
- Stray-pixel warnings.

## Validator Output

Each validation result should include:

- `valid`: whether the frame is safe for output.
- `issues`: structured warnings/errors.
- `metrics`: frame metrics for preview and logging.
- `sanitizedFrame`: optional corrected frame.

## Current Status

The validator is being introduced as a central gate. Existing Toy code must be migrated toward shared frame generation and validator-backed output instead of local ad-hoc pixel maps.

# Glyph-To-Flip Setup

Date: 2026-06-07

GlyphHub exposes a single Glyph Toy service and should be selected from Nothing OS Glyph / Glyph-to-Flip / Always-on Glyph Toy settings when available on the device.

## Setup Checklist

1. Install the debug or release APK.
2. Open Nothing OS Glyph settings.
3. Select GlyphHub as the Glyph Toy if the system exposes the service.
4. Open GlyphHub and enable AOD/default-display if desired.
5. Start one READY Toy from the app or widget.
6. Confirm the phone-back Matrix shows only the selected Toy/default-display path.

## Validation Still Required

- Manual confirmation that Nothing OS lists the updated service.
- Manual confirmation that selecting GlyphHub does not conflict with Nothing system Glyph behavior.
- Manual confirmation that default display respects active Toy ownership and schedule/night mode.
